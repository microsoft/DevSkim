## Do not store tokens or keys in source code.

### Summary
A token or key was found in source code. If this represents a secret, it should be moved somewhere else.

### Details

Secrets in source code pose a threat to the application's components, like
databases and other users, especially if this source code is leaked or shared.
This applies to:

* Users/passwords
* Tokens (JWT's, etc.)
* Hashes
* Encryption keys

Hex values labeled with `md5`, `sha1`, `sha224`, `sha256`, `sha384`, or
`sha512` are treated as digests rather than secrets. This includes image digests
such as `@sha256:...` and algorithm-named properties such as `"sha256": "..."`.
Algorithm names are case-insensitive. Secret names such as `hmac-key-sha256`
and `password_sha256` remain reportable, as do secrets elsewhere on the same line.

### Severity Considerations

Follow these steps:

* Change passwords/keys/secrets on the target components.
* Store them in a secrets vault
* Remove them from your code.
